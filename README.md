
  # User greeting

  This is a code bundle for User greeting. The original project is available at https://www.figma.com/design/t7ceYscQED6h40g6pavz0i/User-greeting.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Publishing on GitHub Pages

  Pushing to the `main` branch automatically builds and deploys the site through
  GitHub Actions. In the repository settings, open **Pages** and set **Build and
  deployment** to **GitHub Actions** once. The site will then be available at:

  `https://ywang179.github.io/testhomepage/`
